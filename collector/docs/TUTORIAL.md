# LignoEMG-16CH 客户采集脚本使用教程

> 面向工业抓取 / 康复 / VLA 训练研究的桌面级 16 通道 sEMG 采集工具
> 配套硬件: LK-M1299-16CH  配套脚本版本: v1.0

---

## 1. 交付清单

打开 `customer_collector/` 文件夹, 你会看到:

```
customer_collector/
├── collect_cli.py            ← 主采集脚本 (命令行)
├── self_check.py             ← 环境自检 (出问题先跑这个)
├── core/                     ← 串口 / 协议 / 滤波模块 (不要修改)
│   ├── ads129x_cmd.py
│   ├── ads129x_data.py

│   ├── eeg_filter.py
│   └── ecg_filter.py
├── data/
│   └── output/               ← 采集数据保存位置
└── docs/
    └── TUTORIAL.md           ← 本教程
```

**唯一需要客户运行的两个文件:**

| 文件 | 用途 |
| --- | --- |
| `self_check.py` | 出问题时第一个跑, 排查环境 |
| `collect_cli.py` | 正式采集时用, 一次采集一次数据 |

## 2. 安装 Python 与依赖 (一次性)

### 2.1 安装 Python

如果电脑没装 Python, 到 <https://www.python.org/downloads/> 下载 3.10 或 3.11 版本.

安装时 **务必勾选** "Add Python to PATH".

### 2.2 安装第三方依赖

打开 PowerShell 或 cmd, 进入 `customer_collector/` 目录:

```bash
cd D:\saunfa\ads1299_python_16ch\ads1299_python_16ch\customer_collector
pip install pyserial numpy
```

如果下载慢, 可用清华镜像:

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pyserial numpy
```

## 3. 连接硬件

按以下顺序操作:

1.  把 16 通道柔性绑带缠到被试者前臂 (注意: 绑带上有 CH1~CH16 丝印, 顺时针绕, 起点在手腕上方约 2 cm 处)
2.  在绑带电极位贴上 Ag/AgCl 一次性电极片 (每通道 1 片贴在肌肉隆起最高点, 1 片贴附近骨性标志作为参考)
3.  把绑带 FPC 排线插头插到采集主板
4.  用 USB 数据线把采集主板接到电脑
5.  等待约 3 秒, Windows 会自动安装 USB-UART 驱动 (如弹出设备管理器, 检查 "端口 (COM 和 LPT)" 下是否多出一个 COM 端口)

## 4. 第一次使用: 跑自检

**强烈建议在第一次正式采集前先跑自检**, 它会一次性检查:

- Python 版本
- 依赖是否装好
- 核心驱动模块是否完整
- 串口是否能找到
- 设备是否真的连上了 (能跑 3 秒短采, 检查采样率与通道数)
- 16 通道是否有复制问题 (CH1 vs CH9)

```bash
python self_check.py
```

正常输出 (简化):

```
== 1) Python 环境 ==
  版本: Python 3.11.x
  [OK]    Python 版本 >= 3.8

== 2) 第三方依赖 ==
  [OK]    pyserial 已安装
  [OK]    numpy 已安装

== 3) 驱动模块 (core/) ==
  [OK]    core/ads129x_cmd.py
  [OK]    core/ads129x_data.py
  ...

== 4) 串口枚举 ==
  - COM5  (USB-SERIAL CH340)  hwid=USB VID:PID=1A86:7523
  [OK]    共 1 个串口

== 总结 ==
  全部通过 (4/4) - 可以开始采集
```

**常见失败原因:**

| 提示 | 解决 |
| --- | --- |
| `缺少 pyserial, 请运行: pip install pyserial` | 回到 §2.2 重装 |
| `未发现任何串口, 请检查 USB 是否插入` | 重新插 USB 线; 在设备管理器看有没有黄色叹号 |
| `数据量过少, 设备可能未连接或 baudrate 不匹配` | 检查 USB 线是否数据线 (有些只能充电) |
| `CH1 与 CH9 相关系数 > 0.99` | 固件 bug 或接线错, 联系供应商 |

## 5. 正式采集: `collect_cli.py`

### 5.1 启动

```bash
python collect_cli.py
```

会出现交互流程:

```
============================================================
  LignoEMG-16CH  客户版命令行采集工具  v1.0
============================================================

客户姓名 / 编号: 张三
采集场景说明: 木板抓握
检测到的串口:
  1. COM5  (USB-SERIAL CH340)
自动选择唯一串口: COM5
打开串口 COM5 @ 2000000 ...
[OK] 串口已打开
[OK] 采集已启动, 按数字键 0-8 标注, q 停止并保存

键位: 0-8 标注阶段  |  q 停止并保存  |  Ctrl+C 强制退出
```

> **注意**: 终端窗口必须保持在前台焦点. 如果鼠标点了别的地方, 按键可能不响应.

### 5.2 9 阶段标注

一次完整的"抓握木板"动作, 建议按下面 9 个阶段依次按键标注:

| 键位 | 阶段 | 中文 | 含义 |
| --- | --- | --- | --- |
| `0` | rest      | 休息 / 静息    | 被试者放松手臂, 用来做基线 |
| `1` | approach  | 1. 接近木块    | 手伸向目标物体 |
| `2` | pregrasp  | 2. 准备抓握    | 手张开, 准备合拢 |
| `3` | contact   | 3. 接触木块    | 指尖刚触到物体 |
| `4` | grasp     | 4. 抓握        | 五指收拢, 真正握住 |
| `5` | lift      | 5. 提举        | 把物体抬离桌面 |
| `6` | hold      | 6. 保持        | 维持抓握 1~3 秒 |
| `7` | place     | 7. 放置        | 把物体放回 |
| `8` | release   | 8. 松开 / 复位  | 五指张开, 手臂归位 |

> **每个阶段保持 2~3 秒**, 中间不要反复按同一个键. 一个完整动作流是 `0 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 0`.

### 5.3 一次采集的完整时序

假设采集 10 个抓握动作:

```
[0]  按下, 静息 2 秒
[1]  按下, 接近 2 秒
[2]  按下, 张开 1.5 秒
[3]  按下, 接触 0.5 秒
[4]  按下, 抓握 2 秒
[5]  按下, 提举 1.5 秒
[6]  按下, 保持 2 秒
[7]  按下, 放置 1.5 秒
[8]  按下, 松开 1.5 秒
[0]  按下, 休息 3 秒 (中间休息, 避免肌肉疲劳)
     → 重复 10 次
[q]  按下, 停止并保存
```

### 5.4 停止与保存

按 `q` 后:

1.  脚本会先发停止指令给设备
2.  在终端打印本次各阶段标注次数 (井号条形图)
3.  自动保存 4 个文件到 `data/output/`:

```
emg_张三_木板抓握_20260705_181430.npz
emg_张三_木板抓握_20260705_181430.csv
emg_张三_木板抓握_20260705_181430_annotations.json
emg_张三_木板抓握_20260705_181430.zip   ← 这个回传给我们
```

| 文件 | 用途 |
| --- | --- |
| `.npz` | numpy 加载, 含 16 通道原始数据 + 标注, 训练用 |
| `.csv` | 16 通道逐样本, 通用软件都能打开 (Excel, MATLAB) |
| `.json` | 元数据 + 标注, 给程序读 |
| `.zip` | 上面三个打包, 客户直接回传这一个 |

### 5.5 紧急中断

- `Ctrl + C` — 强制退出, **不会保存数据** (慎用)
- `q` — 正常停止并保存 (推荐)

## 6. 数据格式说明 (给客户的工程师)

### 6.1 CSV 格式

```
# customer=张三,scene=木板抓握,sample_rate=1000,n_channels=16
sample_idx,CH1,CH2,CH3,...,CH16
0,123.4,567.8,...
1,...
```

- 第一行是注释 (以 `#` 开头)
- 第二行是表头
- 后续每行一个采样时刻, 16 个浮点数 (单位: µV)

### 6.2 NPZ 格式

```python
import numpy as np
z = np.load("emg_xxx.npz", allow_pickle=True)
data = z["data"]            # shape = (n_samples, 16)
sr   = int(z["sample_rate"])  # 1000
anno = z["annotations"]     # 标注列表
print(data.shape, sr)
```

### 6.3 标注 JSON 格式

```json
{
  "customer": "张三",
  "scene": "木板抓握",
  "sample_rate": 1000,
  "n_channels": 16,
  "n_samples": 30000,
  "gesture_def": [
    {"id": 0, "name": "rest",     "name_cn": "休息 / 静息"},
    {"id": 1, "name": "approach", "name_cn": "1. 接近木块"},
    ...
  ],
  "gesture_counts": {"0": 10, "1": 10, "2": 10, ...},
  "annotations": [
    {
      "gesture_id": 1,
      "gesture_name": "approach",
      "gesture_cn": "1. 接近木块",
      "start_ts": 1751715012.34,
      "end_ts": 1751715014.56,
      "duration_s": 2.22
    },
    ...
  ]
}
```

`start_ts` / `end_ts` 是 Unix 时间戳 (浮点秒), 可以直接用 `datetime.fromtimestamp()` 转换.

## 7. 常见问题

### Q1. 串口被别的程序占用

```
[ERR] 打开串口失败: PermissionError(13, '拒绝访问', 'COM5')
```

**解决**: 关闭所有可能用串口的程序 (Arduino IDE, 串口助手, 其他 EMG 软件). 如果还占着, 拔掉 USB 重插.

### Q2. Windows 找不到 COM 口

- 检查 USB 线是否是数据线 (有些只能充电)
- 在设备管理器里看 "端口 (COM 和 LPT)" 有没有新设备, 如果有黄色叹号, 装 CH340 或 CP210x 驱动 (按主板上的 USB-UART 芯片型号)

### Q3. 数据全是 0 或者一条直线

- 检查绑带 FPC 排线是否插紧
- 检查 Ag/AgCl 电极是否失效 (皮肤干燥 / 过期电极 → 接触不良)
- 在 `self_check.py` 里看 "握手成功" 那一行是否打印采样率 1000 Hz

### Q4. CH1 和 CH9 数据一模一样

这是固件 bug, 表现为 `self_check` 警告:

```
[WARN]  CH1 与 CH9 相关系数 0.998 > 0.99, 可能存在通道复制/接线问题
```

**解决**: 联系供应商升级固件, 在那之前只能当作 8 通道用 (CH1~CH8 正常).

### Q5. 想同时采集视频

当前 CLI 不支持视频同步, 如需要:

- 用 OBS 录屏或外接 USB 摄像头
- 采集完成后, 用我们的 `train_combined.py` 工具把 EMG 和视频时间戳对齐

## 8. 采集质量建议

为得到能用的数据集, 建议:

1. **每个被试者采 5~10 分钟**: 至少 30 次完整抓握动作
2. **被试者静息 3 秒, 抓握 5~8 秒**: 不要连续按同一阶段键
3. **多换被试者**: 至少 3 个人, 数据才具有泛化性
4. **环境安静**: 避免强电磁干扰 (电焊机 / 大功率电机)
5. **皮肤准备**: 用酒精棉片擦拭电极位, 干了再贴
